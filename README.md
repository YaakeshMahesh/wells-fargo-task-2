# Wells Fargo Software Engineering Virtual Experience – Task 2

This repository contains my solution for **Task 2** of the **Wells Fargo Software Engineering Virtual Experience Program (Forage)**. The task focuses on implementing the JPA data model for an advisor portfolio management system.

## Tech Stack

- Java
- Spring Boot
- Spring Data JPA
- Maven
- Git & GitHub

## Features

- Implemented JPA entity classes
- Configured entity relationships
- Developed the advisor portfolio data model
- Followed Spring Boot best practices

- `pom.xml` – Maven configuration
- `README.md` – Project documentation
